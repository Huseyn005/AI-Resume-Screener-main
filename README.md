# Shortlist — Resume Screener

A client-side resume screening app built with React, Vite, and Tailwind CSS. Resume files and screening data are stored in the browser.

## Development

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

The Vite development server runs on port 8080.

## Production

Build the static SPA with `npm run build`. The Vercel rewrite configuration serves the app entry point for client-side routes.
